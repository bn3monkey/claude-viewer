GUI Draft v0 — 영역 설명 (항목을 우클릭해 보세요)

  1. Claude 연결: 경로 / 자동 찾기(VSCode 확장 → 일반 설치 경로 순) / 수동 찾기
  2. Projects & Sessions (좌측 상단 20%): 프로젝트 아이콘(클릭 시 File Picker) + 폴더명 + 0/1 1/3 2/2 태그. 세션은 한 줄에 아이콘 · 이름 · 진행 중 / 완료
  3. Project Tree: 프로젝트/세션 선택 시 표시. 디렉터리·파일·빈 공간 우클릭 메뉴, 드래그 이동
  4. Session: 대화, 선택 파일 칩, 모델 드롭다운, 입력창, Commit / Abort
  5. File Viewer: 읽기 전용. .md / .html 은 클릭 → 구문 강조 소스, 우클릭 → "미리보기로 열기"(md 렌더링 탭) / "Browser로 열기"(html). 코드 하이라이트, pdf, docx, 이미지, mp4. AI가 API로 특정 파일을 열 수 있음
